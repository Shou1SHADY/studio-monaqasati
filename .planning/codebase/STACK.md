# STACK.md

## Overview
- **Type**: Next.js Web Application
- **Language**: TypeScript
- **Runtime**: Node.js
- **Primary Framework**: Next.js 15 (App Router)
- **UI Library**: React 19

## Key Technologies
- **Styling**: Tailwind CSS 3
- **Component Library**: Radix UI (headless) + custom components (Shadcn-like)
- **Icons**: Lucide React
- **Form Management**: React Hook Form + Zod
- **AI Integration**: Firebase Genkit + Google GenAI
- **Maps**: Leaflet + React Leaflet

## Database & Backend
- **Primary Database**: Firebase Firestore
- **Authentication**: Firebase Authentication
- **File Storage**: Firebase Storage
- **Hosting**: Firebase App Hosting

## Testing & Quality
- **Unit/Integration Testing**: Jest + React Testing Library
- **End-to-End Testing**: Playwright
- **Linting**: Next.js Built-in (ESLint)
- **Type Checking**: TypeScript

## Build & Deployment
- **Scripts**: Extensive custom PowerShell scripts for validation and checks (`scripts/`)
- **CI/CD**: Configured for Firebase App Hosting
