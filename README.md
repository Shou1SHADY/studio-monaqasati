# مدماك تيك (Madmak Tech)

A multilingual marketplace platform connecting contractors and suppliers for project procurement and RFQ management.

Built with Next.js 15, React 19, Firebase, and Tailwind CSS.

## Quick Start

```bash
npm install
cp .opencode/env.example .env  # fill in your credentials
npm run dev                     # http://localhost:9002
```

## Roles

- **Contractor** — Post RFQs, review offers, manage projects
- **Supplier** — Browse RFQs, submit offers, manage orders
- **Admin** — Oversee users, RFQs, platform stats

See [AUTOMATION.md](./AUTOMATION.md) for available scripts and validation commands.
